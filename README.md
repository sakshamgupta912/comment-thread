# Comment thread playground (GitHub Pages)

This branch holds only the built, static playground for `@fluent/comment-thread`. It shares no history with `main`.

Deploy it from **Settings > Pages > Build and deployment > Deploy from a branch**, branch `gh-pages`, folder `/ (root)`.

The site uses relative asset paths, so it works at any Pages URL. Do not edit these files by hand: rebuild them from the playground source (`npm run build:pages` in `my-app`) and replace the contents of this branch.
